# 현재 프로젝트 결정

## 지침만 분리 적용 — 2026-11-14

- [PR #5](https://github.com/weeeeestern/kirothon-team-019/pull/5)의 역할 분담·QA·결정 기록·압축 훅을 현재 코드에 맞춰 선별 적용한다.
- Supabase 구현, 전용 backend-dev, DB 계약·완료 체크리스트, 이전 작업자의 브랜치·작성자·수행 이력은 가져오지 않는다. 이 지침 적용은 PR 전체 병합이나 기능 검증 완료를 의미하지 않는다.
- 앱 상태·제보·포인트는 `localStorage`, 서버는 Vercel Functions/Vite 외부 API 중계 구조다. 길찾기 이상 신호의 범위는 현재 구현과 스펙을 따르며 공식 실시간 운행 이상 탐지로 과장하지 않는다.
- 홈·키로의 방은 사용자가 선택한 옷을 유지한다. 상황 의상으로 무조건 덮어쓰는 규칙은 적용하지 않는다.
- 역할별 소유권과 검증 절차는 `AGENTS.md`, `docs/AGENT_WORKFLOW.md`에 둔다. Kiro lead는 조정 전용이며 직접 파일을 수정하지 않는다.
- 압축 시 Git 메타데이터만 로컬에 저장한다. 대화 요약과 `summary_path` 파일은 복사하지 않는다. 스냅샷은 무시 대상이며 phase별 최근 20개만 유지한다.
- 커밋·푸시는 현재 사용자 요청에 따른다. 고정 브랜치·작성자·공동 작성자를 강제하지 않는다.

## 변경 기록 방법

결정을 바꿀 때 이유·적용 범위·근거를 함께 갱신한다. 테스트·API·배포 결과는 실제 실행 근거와 미확인 범위를 구분하고, 이 문서를 과거 작업 완료 목록으로 사용하지 않는다.
