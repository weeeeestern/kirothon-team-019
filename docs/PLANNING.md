# 우리동네지킴이 (가칭) — 기획서

> **평소와 다른 날에만 울리는 출퇴근 알림**
> 캐릭터: 키로 · 문서 범위: 화면 설계·데모 시나리오 제외 (와이어프레임 착수 전 단계)

---

## 1. 서비스 정의

서울 대중교통 이용자에게, **내 경로와 출발 시각에 실제로 영향이 있는 날에만**
"무엇이 / 평소 대비 얼마나 / 무엇을 할지"를 한 건으로 알려주는 서비스.

> **핵심 주장** — 알림의 가치는 정확도가 아니라 '안 울리는 날'에서 나온다.

---

## 2. 배경

### 2.1 문제

- 기존 교통앱은 고정 임계값으로 매일 비슷하게 울린다
  → 사용자는 결국 알림을 끄고, 정작 중요한 날을 놓쳐 **10~20분을 잃는다**
- 공식 API에 없는 이상(파업 예고, 집회, 임시 우회, 정류장 폐쇄)은 어떤 앱도 알려주지 않는다
- 같은 길을 다니는 사람끼리 동일한 불편을 겪지만 정보를 나눌 수단이 없다

### 2.2 왜 아직 안 풀렸는가

| 원인 | 설명 |
|---|---|
| 기준선이 없다 | "평소"를 모르니 "다름"을 판정할 수 없다 |
| 개인화가 없다 | 노선 전체 기준으로 울리지, 내 구간·내 시각 기준이 아니다 |
| 공급원이 하나뿐이다 | 공식 데이터에 없는 이상은 영구적 사각지대다 |

### 2.3 감지 대상

- 지하철·버스 파업, 운행 지연
- 버스 노선 임시 우회, 정류장 폐쇄
- 폭우·폭설·폭염·미세먼지 급변
- 행사·집회로 인한 도로 통제 (마라톤, 축제 등)
- 공휴일 다음 날 등 패턴 변화

## 3. 대상 사용자

서울에서 지하철·버스로 이동하는 사람과 그 주변(가족·동료·이웃)

| 페르소나 | 경로 | 특징 |
|---|---|---|
| 출근러 | 2호선 / 평일 08:00 출발 | 지연에 민감, 알림 피로도 높음 |
| 하원길 보호자 | 버스+도보 / 평일 17:30 | 본인뿐 아니라 아이 동선의 이상에도 반응 |

## 4. 핵심 컨셉

### 1) "평소와 다르다"가 아니라 "내 행동을 바꿔야 할 때만" 알린다

```
판정식 = 평소 대비 편차 × 내 경로 겹침 × 내 출발 시간대 겹침
```

### 2) 알림 한 건에는 반드시 '할 일'이 들어간다

> "2호선 평소 혼잡 60% → 오늘 95%. 10분 일찍 출발하세요"

### 3) 타이밍은 2단계로 나눈다

| 유형 | 예시 | 전달 시점 |
|---|---|---|
| 예정형 | 파업, 마라톤, 예정 공사 | **전날 밤 예고** |
| 돌발형 | 사고, 급작 혼잡, 기상 급변 | **출발 15~20분 전** |

### 4) 캐릭터 '키로'가 알림 그 자체다

- **상태 반영** — 평범=졸고 있음 / 공사=안전모 / 비=우비 / 미세먼지=마스크 / 행사 통제=머리띠
- 알림 0건인 날에도 "오늘도 평범"이 한눈에 전달된다
- **포인트로 키로를 꾸민다.** 포인트는 이상을 제보할 때, 그리고 내 제보가 다른 사용자에게 "도움됨"을 받을 때 얻는다

### 5) 쓸수록 나에게 맞춰진다

출발 시각·경로·피드백 이력을 계속 학습해 임계값과 기준선을 개인화한다.

---

## 5. 기능 정의

### 5.1 경로 등록

- 자치구 선택 → 역/정류장 + 출발 시각 등록 (복수 경로 지원)
- **길찾기는 제공하지 않는다.** 사용자가 다니는 길을 직접 등록하는 방식
  - 사유: 국내 대중교통 길찾기 공개 API가 사실상 부재
- **개인정보 원칙** — 등록 경로만 사용, 상시 위치 추적 없음

### 5.2 기준선 생성

- **단위**: `[요일 유형 × 30분 시간대 × 지역/구간]`
- **요일 유형**: 평일 / 주말 / 공휴일 / 공휴일 다음날
- 개인 이력을 모으지 않고 **공공데이터로 지역 기준선을 먼저 만든다**
  → 가입 첫날부터 판정 가능, 개인 데이터 수집 불필요
- 이력이 부족한 구간은 통계·평년값을 초기값으로 쓰고 **"학습 중"**으로 표시

### 5.3 이상 판정

| 항목 | 정의 |
|---|---|
| 편차 | (오늘 값 − 기준선 평균) / 기준선 표준편차 |
| 경로 겹침 | 이상 발생 지점이 내 등록 구간에 포함되는 정도 (0~1) |
| 시간 겹침 | 이상 지속 시간이 내 출발 시각 ± 윈도우에 걸치는 정도 (0~1) |
| **영향도** | 편차 × 경로 겹침 × 시간 겹침 |

- `영향도 ≥ 개인 임계값 T` 일 때만 알림 생성. 미만이면 **알림 0건**
- `T`는 공통 초기값에서 출발해 사용자 피드백으로 개인별 조정

### 5.4 알림 생성·전달

**구성 3요소 (고정 포맷)**

| 요소 | 예시 |
|---|---|
| 무엇이 | "2호선 강남~잠실 구간 혼잡" |
| 평소 대비 얼마나 | "평소 60% → 오늘 95%" |
| 권고 한 줄 | "10분 일찍 출발하세요" |

- 전달 시점은 **컨셉 3의 2단계 규칙**을 따른다
- 각 알림에 "도움이 됐어요 / 필요 없었어요" 피드백 버튼
- 평범한 날에도 하루 1회 **'오늘 평범도'** 점수를 제공해, 알림 0건이 '서비스 미작동'으로 오해되지 않게 한다

### 5.5 시민 제보 루프

```
제보 등록 → 같은 경로 2~3명 확인 → 신뢰도 상승
         → 해당 경로 사용자에게 알림 → "도움됨" 반응
         → 제보자 포인트 + 민감도 조정
```

- 사용자가 이상을 직접 등록 (유형 / 위치 / 시각 / 한 줄 설명)
- **역할**: 공식 API가 없는 이상(파업·집회·임시 우회)과 지자체별 공사 정보 편차를 메우는 **유일한 공급원**

### 5.6 포인트 · 레벨 · 키로 꾸미기

**획득** (제안값)

| 행동 | 포인트 |
|---|---|
| 이상 제보 등록 | +10 |
| 내 제보가 "도움됨" 획득 | +5 / 건 |
| 알림 피드백 응답 | +1 |

**사용**

- 키로 꾸미기 아이템(의상·소품) 해금
- **이상 상황 한정판 아이템** — 해당 이상을 제보한 사용자만 그날 획득
- 레벨: 누적 포인트로 상승, 레벨별 아이템 해금

> **왜 필수 기능인가** — 5.5의 제보 공급을 유지시키는 유인 장치다.
> 제보가 멈추면 사각지대가 그대로 남으므로 부가 기능이 아니다.

### 5.7 개인화 학습

- **임계값 개인화** — 피드백 누적으로 `T`를 상·하향
- **출발 시각 보정** — 실제 앱 사용 시각 패턴으로 등록 시각 보정
- **구간 기준선 정밀화** — 내가 자주 쓰는 구간의 기준선을 우선 축적
- **투명성** — 알림마다 판단 근거를 한 줄로 노출하고, 학습 상태(학습 중 / 안정)를 표기

## 6. 데이터 전략

### 6.1 원칙

1. 개인 이력 수집 없이 **공공데이터로 지역 기준선**을 생성한다
2. 공식 데이터로 못 메우는 영역은 **시민 제보**로 보완한다
3. 실데이터는 **사전에 수집해 JSON으로 번들**하고 수집 시각을 표기한다
   → 런타임 API 호출 없음, 외부 장애에 영향받지 않음

### 6.2 소스별 현황

> ⚠️ **현재 전 항목 미검증 상태입니다.**

| 소스 | 쓰는 신호 | 확인 정도 |
|---|---|---|
| 기상청 단기예보 (공공데이터포털) | 강수·기온·풍속 | 존재는 확인, 공식 문서 미확인 |
| 서울시 실시간 도시데이터 (113곳) | 장소별 혼잡 단계 | 확대 발표만 확인, 제공 항목 미확인 |
| TOPIS 돌발상황정보 | 사고·공사·통제 | 개발 글만 확인, 행사·마라톤 통제 포함 여부 미확인 |
| 지하철 실시간 도착정보 | 도착 간격 이상 | 사용 앱은 많으나 공식 사양 미확인 |
| 서울 버스 도착정보 (TOPIS 기반) | 배차 간격 이상 | 앱들이 TOPIS 출처로 표기, 사양 미확인 |
| 지하철 혼잡도 통계 | 기준선 초기값 | 연구·보도만 확인, 제공 형태 미확인 |
| 에어코리아 | 미세먼지 | 미확인 |
| 파업·집회 | — | **공식 API 없음 → 사용자 등록으로 대체** |

### 6.3 대응

- 착수 즉시 소스별로 **키 발급 → 샘플 호출 → 응답 스키마 확인** 순으로 검증
- 검증 통과분만 실데이터로 쓰고, 실패분은 합성 데이터로 대체 표기
- 어떤 소스를 실제로 썼는지 결과 화면과 README에 **소스별로 명시**

## 8. 성공 지표

> 합성 시나리오 기준

- 평범한 날 **알림 0건**
- 주입한 이상의 **탐지율 80% 이상**
- 고정 임계값 방식 대비 **알림 수 50% 이상 감소**
- *(참고 지표)* 알림 수 대비 "도움됨" 비율

## 9. 구현 범위 (4시간 / 4인)

### 포함

- 경로 등록 (페르소나 사전 세팅 + 수정 가능)
- 공공데이터 기반 요일·시간대별 지역 기준선
- 이상 판정 엔진 (5.3 판정식)
- 이상일 때만 알림 + 판단 근거 한 줄 + 오늘 평범도
- 키로 상태 반영 (5종) 및 꾸미기
- 포인트·레벨 시스템 (획득·사용·해금)
- 시민 제보 등록 및 신뢰도 검증
- 합성 시나리오 평가

### 기획에는 포함 / 해커톤 구현에서는 설계만

- **지속 학습 개인화** — 임계값 조정까지만 구현, 출발 시각 보정·구간 기준선 정밀화는 설계 문서로 대체

### 제외 — 확장 계획으로만 언급

- 길찾기 알고리즘·지도 API, 최적 루트 공유
- AI 기반 제보 자동 검증 (룰 기반 2~3인 확인으로 대체)
- 따릉이 대여소 재배치 연동
- 치안·실종자 정보 연계
