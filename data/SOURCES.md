# 데이터 소스와 검증 기록

기준일: 2026-11-14. **과거 공공데이터 기준선과 현재 상황·합성 시연을 구분한다.** 파일에서 계산한 기준선이 있다고 해서 실시간 이상 탐지까지 검증된 것은 아니다.

## 사용자가 제공한 실제 파일

| 소스 | 사용 내용 | 기준·단위 | 출처 |
|---|---|---|---|
| 서울교통공사 지하철 혼잡도 | 제공된 5개 파일 모두 스키마·중복·결측 검증, 최신 20260930 파일을 조회에 사용 | 평일·토요일·일요일, 호선·역·방향, 30분 평균 혼잡도 % | [서울 열린데이터광장](https://data.seoul.go.kr/dataList/OA-12928/S/1/datasetView.do) |
| 서울교통공사 역별 일별 시간대별 승하차인원 | 2025년 일별 원본을 역·호선·승하차·요일·시간대별 집계 | 명, 일별 평균·표본 표준편차(n−1)·표본일수 | [공공데이터포털](https://www.data.go.kr/data/15048032/fileData.do) |
| 에어코리아 최종확정 측정자료 | 제공된 2026년 1~4월 파일에서 서울 도시대기 측정소만 사용 | PM10·PM2.5, µg/m³, 시간대별 평균·표본 표준편차·유효 표본수 | [에어코리아](https://www.airkorea.or.kr/web/last_amb_hour_data?pMENU_NO=123) |

원본은 다운로드 폴더에서 읽기만 한다. 큰 원본을 저장소에 복사하지 않는다. 파일명·SHA256·파일 크기·파싱 행수·사용 행수·결측·중복 검사 결과와 실제 가져온 시각은 [`src/data/public/provenance.json`](../src/data/public/provenance.json)에 기록한다. 이전 혼잡도 파일은 검증 기록으로 남기고 최신값과 섞어 평균내지 않는다.

재생성:

```sh
python3 scripts/collect/import_public_data.py --source-dir ~/Downloads
python3 -m unittest discover -s scripts/collect -p 'test_*.py'
npm --prefix src test -- features/baseline/publicBaseline.test.ts
```

CSV는 UTF-8 또는 CP949를 판별한다. XLSX는 셀 주소와 시트 관계를 읽어 스트리밍 처리하며, 빈 셀을 0으로 바꾸지 않는다. 최신 혼잡도 파일의 요일별 시트와 이전 파일의 요일 열을 모두 처리한다. 데이터는 동적 import로 필요한 화면에서 불러온다.

## 비교할 때 지켜야 하는 구분

- **혼잡도 %**는 분기별 시간대 평균이다. 일별 원시 혼잡도 값이 없으므로 일별 표준편차는 계산하지 않는다.
- **승하차 인원**은 개찰구 이용량이다. 혼잡도 %와 단위가 다르며 열차 혼잡도나 현재 승객 수로 변환하지 않는다. 승차·하차, 호선·방향을 각각 유지한다.
- 역 이름이 같아도 호선과 방향이 다르면 별도 결과를 반환한다. 정확한 노선·방향을 모르면 여러 결과를 표시한다.
- 지하철 00:00~00:59는 원본의 24시대로, 이전 **운행일** 요일을 사용한다. 제공되지 않은 시간대는 근처 값으로 메우지 않는다.
- 2025년 승하차와 대기질 집계의 요일은 실제 달력의 평일·토요일·일요일이다. 공휴일·연휴 다음날은 별도 분리하지 않았으며 공휴일 보정 기준이라고 표시하지 않는다.
- 대기질 원본의 01~24시는 측정 구간의 끝 시각이다. 01시는 00:00~01:00, 24시는 23:00~24:00으로 저장한다.
- 유효 표본 수가 0이면 결측, 1이면 표준편차는 `null`이다. 정상 측정값 0은 유지한다.
- 과거 기준선만으로 현재 상태나 알림 여부를 판단하지 않는다. 합성 시연 엔진의 범용 지수와 실제 혼잡도·대기질 값을 서로 비교하지 않는다.

## 별도 공공 API 연결 확인

2026-11-14 재시도 결과이며 **호출 검증과 화면 연동은 별개**다. 키 값이나 키가 포함된 URL은 기록하지 않는다.

| 소스 | 호출 결과 | 파일 기준선과의 관계 |
|---|---|---|
| 서울시 실시간 도시데이터 | 강남역 `INFO-000`; 인구 16:00, 날씨 16:20 응답 확인 | 지원 지역의 현재 날씨·대기·도로통제. 인구 혼잡도와 열차 혼잡도 %는 다름 |
| 지하철 실시간 도착 | 강남 `INFO-000`; 16:28대 응답 확인 | 도착정보이며 현재 열차 혼잡도 측정값은 아님 |
| TOPIS 돌발상황 | `INFO-000`; 총 13건 중 5건 조회 | 사고·도로통제 정보 |
| 기상청 초단기실황 | HTTP 403, `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 현재 사용 불가; 시간 경과만으로 해결 보장 안 됨 |
| 에어코리아 실시간 API | HTTP 403, `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 위 과거 파일 파싱 성공과 별개 |
| 서울 버스 도착 | HTTP 401, 등록되지 않은 서비스키 | 현재 사용 불가 |

파업·집회 시민 제보와 합성 평가 시나리오는 별도 시연이다. 이웃 A/B는 실제 계정이 아니며 위치 확인도 하지 않는다. `src/data/synthetic/`, 기존 합성 성능 수치, `sources.json`의 합성 신호를 실제 교통 성능으로 바꿔 표기하지 않는다.
