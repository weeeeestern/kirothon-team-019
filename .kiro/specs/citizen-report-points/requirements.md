# 요구사항: 시민 제보와 포인트 (citizen-report-points)

담당: C. 출처: `docs/PRD.md`, `docs/기능명세서.xlsx` 영역 5(시민 제보 루프), 7(포인트·레벨). 키로 꾸미기 화면은 `app-ui-kiro` 스펙에서 다룬다.

## 소개

공식 API에 없는 이상(파업, 집회, 임시 우회, 정류장 폐쇄)을 사용자 제보로 메운다. 제보가 멈추면 사각지대가 남으므로, 포인트와 키로 아이템 해금으로 제보를 유지시킨다.

## 요구사항

### 1. 이상 제보 등록

**사용자 스토리:** 제보자로서, 내가 본 이상을 한 줄로 등록해 같은 길을 다니는 사람에게 알리고 싶다.

1. 사용자가 유형, 위치, 시각, 한 줄 설명을 입력하면 시스템은 제보를 등록하고 '검증 대기' 상태로 두어야 한다.
2. 필수 입력(유형, 위치, 시각)이 비어 있으면 시스템은 제보를 등록하지 않고 빈 항목을 알려야 한다.
3. 제보가 등록되면 시스템은 제보자에게 +10 포인트를 적립해야 한다.
4. 한 줄 설명은 시스템이 길이를 제한(예: 100자)하고 초과분은 입력되지 않게 해야 한다.

### 2. 제보 신뢰도 검증 (룰 기반)

1. 같은 경로를 쓰는 서로 다른 사용자 2명이 확인하면 시스템은 제보 신뢰도를 '확인됨'으로 올려야 한다.
2. 같은 사용자가 같은 제보를 두 번 확인해도 시스템은 한 번으로만 센다.
3. 제보자 본인의 확인은 확인 수에 포함하지 않는다.
4. 확인이 부족한 제보는 신뢰도가 오르지 않고 '검증 대기'로 남으며, 알림으로 전달되지 않는다.
5. AI 기반 자동 검증은 하지 않는다. 확장 계획으로만 둔다.

### 3. 제보 기반 알림과 '도움됨'

1. 신뢰도가 오른 제보는 시스템이 같은 경로 사용자에게 알림 후보로 넘겨야 한다. 최종 알림 생성은 `anomaly-engine`이 영향도로 판정한다.
2. 알림을 받은 사용자가 '도움됨'으로 반응하면 시스템은 제보자에게 건당 +5 포인트를 적립해야 한다.
3. 같은 사용자가 같은 제보에 '도움됨'을 여러 번 눌러도 포인트는 한 번만 적립한다.

### 4. 포인트와 레벨

1. 시스템은 알림 피드백 응답 시 +1 포인트를 적립해야 한다.
2. 시스템은 누적 포인트를 합산하고, 레벨 구간에 도달하면 레벨을 올려야 한다.
3. 포인트는 감소하지 않는다(레벨은 누적 기준). 아이템 해금은 레벨 도달 또는 한정판 조건으로 한다.

### 5. 키로 아이템 해금

1. 레벨이 오르면 시스템은 그 레벨의 아이템을 해금해야 한다.
2. 시스템은 사용자가 어떤 이상을 제보한 날에 한해 해당 이상의 한정판 아이템을 제보자에게만 부여해야 한다.
3. 한정판은 제보한 날의 자정이 지나면 새로 얻을 수 없고, 이미 얻은 아이템은 유지한다.
4. 아이템 이름은 렌더러(`KiroAvatar`)의 `OUTFITS` 키를 그대로 쓴다.

### 6. 기존 제보 지도 표시 (2026-11-14 범위 변경)

1. 제보 화면 상단에 브라우저에 저장된 기존·신규 제보의 위치를 카카오 지도로 표시한다. 실제 다중 사용자 공유 데이터로 표현하지 않는다.
2. 동일 위치의 제보는 건수를 묶어 표시하고, 마커 선택 시 유형·설명·발생 시각·등록일·확인 상태를 보여 준다.
3. 만료된 제보도 기본 표시하되 당일 제보만 보는 필터를 제공하고 상세에 만료 상태를 표시한다. 알림 유효 기간은 변경하지 않는다.
4. 경로의 저장된 출발·도착 좌표 또는 정확히 이름이 일치하는 장소 검색 결과만 사용한다. 불명확하거나 조회 실패한 위치를 임의 좌표로 대체하지 않고 미표시 건수와 재시도를 제공한다.
5. 기존 저장 데이터 형식을 유지한다. 경로가 삭제돼도 제보 목록을 유지하며, 장소 조회가 가능하면 지도에 표시한다.

## 범위 밖

- AI 제보 검증, 제보 서버 저장(브라우저 `localStorage`에 저장).
- 같은 경로의 다른 사용자는 해커톤에서 시뮬레이션한 사용자로 대체한다(실제 다중 사용자 없음).

## 미확정 사항 (가정 포함)

| 항목 | 가정 | 확정 필요 |
|---|---|---|
| 포인트 획득량 | 제보 +10, 도움됨 +5, 피드백 +1 (제안값) | 팀 확정 |
| 레벨 구간 | Lv1 0, Lv2 20, Lv3 50, Lv4 100, Lv5 200 | 팀 확정 |
| 어뷰징 대응 | 같은 사용자 중복 확인·중복 '도움됨'은 1회만 인정, 그 외는 범위 밖 | 정책 |
| 제보 유효 기간 | 제보 시각 기준 당일 자정까지 | 정책 |
