## 상태 해석

- 체크된 항목은 기존 구현 기록이며 최신 통합 검증은 `BUILD_REPORT.md`를 따른다.
- **남음**은 전체 요구사항을 아직 확인하지 못한 작업이다. 전체 요구사항과 실제 모듈을 대조해 완료를 표시한다. 계획과 파일명이 달라진 경우 아래 통합 위치를 따른다.
- **시연 범위 밖**: 실제 사용자 계정·서버 동기화·예약 푸시 발송·상시 위치 추적. 앱 내 제보 확인과 계산된 전달 시각을 실제 다중 사용자·발송 완료로 해석하지 않는다.

구현 위치 보정: 타입·상수·`toAnomaly`는 `reportStore.ts`, 레벨·해금은 `ledger.ts`, 영속 상태는 `state/store.ts`에 통합했다. 계획상의 분리 파일을 추가 생성하는 작업은 시연 범위 밖이다.
