# 결정 기록

- 작업 시작과 대화 압축 후 `docs/DECISIONS.md`를 읽고 실제 코드·Git 상태와 대조한다.
- 기록은 현재 구조와 합의한 제약을 보존한다. 특정 작업자의 브랜치·작성자나 검증되지 않은 완료 이력을 일반 규칙으로 옮기지 않는다.
- 현재 사용자 지시가 과거 결정을 변경하면 관련 문서를 함께 갱신한다. 통상적인 구현 선택은 담당자가 해결하고, 필요한 정보나 권한이 실제로 없을 때만 질문한다.
- 비밀 값, 대화 원문, 인증 URL은 결정 기록과 압축 스냅샷에 넣지 않는다.
