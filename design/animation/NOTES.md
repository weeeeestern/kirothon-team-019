# 키로 소프트 시안 — 메모

첫 시안(`outfits.png`)의 구성과 공식 실루엣을 유지한 채, 선·색·움직임만 부드럽게 다듬었습니다. 몸 패스와 눈 위치·눈 글리프(KiroCrew)는 바꾸지 않았습니다. 팔다리는 없습니다.

부드러운 처리: 액세서리는 둥근 끝과 두툼한 곡선, 까만 외곽선 대신 소프트 잉크 `#2A1F3D`, 몸통에 아주 옅은 그라데이션과 아래 그림자, 타일은 채도를 낮춘 파스텔(파업 산호 `#E8928A`, 공사 피치 `#F3C98A` 등), 볼터치는 번진 핑크, 안내판 모서리는 더 둥글게.

## 표정 → 앱 순간

| 표정 | KiroCrew | 언제 |
| --- | --- | --- |
| 평범 졸음 | `sleepy`, 입 없음, Zzz | 알림 없는 아침, 홈 기본 상태 |
| 기쁨 | `canon` + `smile`, 볼터치 | 알림에 “도움됨”을 받았을 때 |
| 윙크 | `wink` + `smile`, 볼터치 | 알림을 확인하고 닫을 때 |
| 하트눈 | `heart` + `smile`, 볼터치, 하트 FX | 새 옷을 획득했을 때 |
| 반짝 | `sparkle` + `grin`, 볼터치, 반짝 FX | 한정판 옷이 열렸을 때 |
| 놀람 | `wide` + `raised` + `oh` | 이상이 처음 감지됐을 때 |
| 걱정 | `squint` + `flat` + `wobble` | 혼잡·지연이 큰 날 |
| 졸린 하품 | `sleepy` + `open` | 밤늦게 앱을 열었을 때 |
| 뿌듯 | `closed` + `smile`, 볼터치 | 제보가 확인·도움됨을 받았을 때 |
| 삐짐 | `squint` + `flat` + `smirk` | 며칠째 앱에 안 들어왔을 때 |
| 응원 | `sparkle` + `smile`, 볼터치 | 출발 전, “지금 나가면 돼요” |
| 잠 | `closed`, Zzz, 어두운 타일 | 밤 11시 이후, 키로가 잠든 상태 |

## 애니메이션 → 트리거 · 길이 · 이징

모두 스프링 또는 ease-in-out이고, 끊기는 스냅·강한 쉐이크는 쓰지 않습니다.

| 움직임 | 트리거 | 길이 | 이징 |

| 둥실 float | 홈 대기, 기본 루프 | 4.8s, 무한 | `cubic-bezier(0.37, 0, 0.24, 1)` · 진폭 16px |
| 느린 깜빡임 | 눈 뜬 표정 | 6.4s, 무한 | `cubic-bezier(0.45, 0.05, 0.25, 1)` · 중간만 살짝 감음 |
| Zzz | 평범 졸음, 잠 | 4.2s, 엇갈림 | 같은 soft 커브, 천천히 떠올라 사라짐 |
| 하품 | 밤늦게 앱을 염 | 2.8s, 루프 | 눈꺼풀이 처지고 입이 천천히 열림 |
| 모자 톡 착용 | 공사 알림, 옷 장착 | 1.05s, 한 번 | `cubic-bezier(0.34, 1.15, 0.64, 1)` · 약한 스쿼시 후 안착 |
